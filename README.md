# Low-Light Object Detection
A computer vision project focused on improving object detection accuracy in low-light and low-visibility environments.

## Overview
This project addresses the performance degradation of traditional object detection models in dark scenes.

## Key Implementations
- Low-light image enhancement (adaptive brightness adjustment & denoising)
- Fine-tuned YOLOv12 model on a custom low-light dataset
- Model optimization for real-time inference speed
